# READING THE FILE

- The file aims to explain an enterprise end-to-end AI Baseline/Reference Architecture.
- The document has been divided into logically separated pages and sections.
- The first page is a title page, followed by the "Presentation Agenda".
- The following pages contain "Architecture Diagrams" for the relevant sections.
- If you have difficulty reading the diagrams due to resolution issues, the following files will help:
  - `details.md`: It is the raw source of the presentation. You can read it in any Markdown editor.
  - If you have trouble focusing on the Mermaid charts in the presentation PDF or `details.md` file, please follow the instructions below:
    - The `./presentation` directory contains the source "Mermaid charts" and "Mermaid-to-PNG conversion" files to provide a better view than the PDF file.
    - You can open a source Mermaid chart file (`.mmd`) in a regular text editor, then copy and paste it into [https://mermaid.live/](https://mermaid.live/) or [https://mermaid2img.com/editor](https://mermaid2img.com/editor) to get a better view.
    - Or you can go directly to the PNG files in the `./presentation/image` directory using a regular image viewer.
